Contatos de lâmina no joystick são prováveis; pinagem e características elétricas não foram confirmadas. Os documentos distinguem CONFIRMADO, PROVÁVEL e NÃO IDENTIFICADO. Nenhum desenho constitui instrução de ligação definitiva.
